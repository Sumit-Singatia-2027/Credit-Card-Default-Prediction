# Credit-Card-Default-Prediction
End-to-end ML pipeline for predicting credit card default risk on a high-dimensional dataset (96K+ rows, 1,216 features). Includes memory-efficient KNN imputation, PCA-based dimensionality reduction (1,216 → 270 features), and comparison of Logistic Regression, Random Forest, and XGBoost with hyperparameter tuning for imbalanced classification.
